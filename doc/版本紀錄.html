版本紀錄

每一條開頭標 [流量] 或 [690]。TIPO flow check 的版本紀錄照抄 [流量] 的條目。

8.1.0 — 2026-10-05

  • [690] 新增 690 資轉監控:伺服器每 10 分鐘讀 [s690] 通知信(Gmail 唯讀),判定每個轉置系統每天 / 每期、每個步驟是成功、失敗、無資料、該到沒到還是還沒跑到。新頁籤「690資轉」(每日資轉、TWA 公開、TWB 公告、其他作業、KM 登記)與「信件與連線」。
  • [690] 失敗的「失敗」兩個字直接連到那封信附的 log,自動捲到 error: 那一行。
  • [690] KM 登記:在 KM「資料轉置登記」的書目、全文、每日執行項目表格自動填格(打 v、TAG、Biblio / Gazette SUD 填 L1 寫入筆數),只填空格、不覆寫人填的值;按「寫入 KM」才寫,寫之前看得到填好的預覽,也可以手動改格。
  • [690] 流量預算:只抓主旨與時間,只有少數信才下載全文。實測第一次抓 45 天 495 封共 2.75 MB。
  • [690] 新增 690授權.bat(Gmail 授權 + 信箱統計)與 requirements-690.txt。690 的套件裝不起來、或沒有 program/xfer690/ 時,流量監控照常啟動。
  • [690] Gmail 授權改成 Google 直接導回主程式(127.0.0.1:8765),修好按「授權」後一直等待到逾時的問題;在新分頁開 Google 同意頁。
  • [690] 新增 TW英譯En 的公告英譯 / 公開英譯兩張 KM 表。畫面上的「Wiki」改稱「KM」。
  • [流量] 「排除內網流量」一律開啟,拿掉開關。能不能排除仍看是否以管理員身分啟動。
  • [流量] 每頁卡片標題放大(12px → 15px)。
  • [流量] 流量報表逐時畫面的「← 每日」改成淡紫膠囊按鈕(跟 690 的返回鈕同一款)。
  • [流量] 淺色主題:外觀選單的「外觀」標題、「暴增紀錄」的 🔺 數字改成看得清楚的顏色。

8.0.0 — 2026-10-02

專案改為「流量監控 + 690 資轉監控」(690 在 8.1.0 加入)。

  • [流量] 移除 GPSS 檢索相關功能:檢索控制台、爬取統計、檢索進度三個頁籤,年度統計(年度統計.bat)與月進度(月進度.bat)整個拿掉。流量監控頁上的「可用上限偵測」開關、今日達標動畫、檢索額度警告橫幅也一起拿掉。
  • [流量] 新增「流量報表」頁籤:每天一根堆疊柱,分出 ssh / Claude Code / VS Code 與其他,可切合計 / 上傳 / 下載與期間;點某一天看那天 8–20 點的逐時折線圖。用來截圖跟公司反映連線問題。
  • [流量] 新增每日用量統計(data/machines/daily_stats_<機器>.json):每天一筆、長期保存,不像逐分鐘明細只留 31 天。要分開統計的程式可在 config.json 的 report_apps 調整。
  • [流量] 新增內網排除診斷(diag_lan.bat):逐連線列出對方 IP、內外網分類與收發量,並和執行中主工具的實扣量對照。
  • [流量] count_ranges 預設改為空清單(原本是 10.65.0.0/16)。需要時在 config.json 自行加。
  • [流量] 安裝只需要 psutil;啟動時不再安裝 openpyxl、playwright、chromium。
  • [流量] 新增 同步到TIPO flow check.bat:由這裡產生 TIPO flow check(只含流量監控、流量報表、內網診斷),只覆蓋程式,不碰同事的 data/ 與 config.json。TIPO flow check 版號從此跟 flow_check 一致。
