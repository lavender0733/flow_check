## 改程式時要記得

- **同步 TIPO flow check**:改完流量程式 → `同步到TIPO flow check.bat` 看預覽 → 命令列加 `--apply` 輸入 y。
  `data/`、`config.json`、`desktop.ini` 一律不碰。在 `program/core/` 新增檔案時,想清楚 TIPO 需不需要
  (`tools/sync_tipo.json` 的 `copy` / `exclude`)。TIPO 的版本紀錄由人照抄 `[流量]` 條目。
- **690 的相依不要寫進 `requirements.txt`**(會被同步到 TIPO),放 `requirements-690.txt`;`program/xfer690/` 不在同步清單裡。
- **`stop_monitor.bat` 用「命令列含 `traffic_monitor.py`」找程序來停**,那個檔名不能改。
- **CSS 的 class 名稱別跟 `web/style.css` 的全域樣式撞名**(例如 `.sub`):撞到會吃到全域的顏色,
  「公開 / 公告」按下後看不見就是這樣來的。淺色主題的 `--pop-bg` 是深紫,淺底配色的內容不要放在它上面。
- **用腳本改檔時核對行尾**(這個資料夾的檔案有 LF 也有 CRLF);`git diff --stat` 數字異常放大就是行尾被改了。
