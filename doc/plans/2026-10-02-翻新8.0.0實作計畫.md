# Flow Check 翻新 8.0.0 — 實作計畫

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** flow_check 從「流量監控 + GPSS 批次檢索」翻新成「流量監控 + 690 資轉監控」的 8.0.0。先移除 GPSS 檢索、檢索進度、爬取統計、年度統計,README 改寫;再做一支同步腳本,把流量相關的程式複製到同事用的 TIPO flow check。

**Architecture:** 不搬檔案位置。從後端的路由表、`storage.py`、`traffic_monitor.py`,前端的頁籤和 `main.js`,把 GPSS 相關的部分整段刪除。流量頁原本借用檢索頁的 `loadConfig`,改成自己讀設定。同步腳本依「要複製的清單」和「路徑對應表」產生同事版:只覆蓋程式,不碰對方的資料。

**Tech Stack:** Python 3.13 標準函式庫、psutil;前端為傳統 `<script>`,沒有打包工具;同步腳本用 Python 寫,由 `.bat` 啟動。

**Spec:** 沒有另寫設計文件。依據是使用者 2026-10-02 在對話中的決定,整理在下方「決定」一節。

    # 依 plan 的結果把 staged 的檔案寫進 dst,並刪掉 remove 清單的檔案
