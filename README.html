Flow Check — 局網流量監控 + GPSS 批次檢索 v7.3.0

一個放在自己電腦上的小工具,做兩件事:

  • 看今天用掉多少網路流量(對著每日 2GB 的額度)
  • 在同一個網頁裡批次檢索 TIPO GPSS 專利

平時在背景執行,要看時打開瀏覽器就好。

檢索有兩種方式:官方 API(快、省流量,需要一組驗證碼)或傳統前端(直接操作網頁、不用驗證碼,但較慢、較耗流量)。

也支援多台電腦一起跑:把資料夾放在 Google Drive 共用,各台資料自動分流、統計自動合計(設定見下方「啟動 / 關閉」)。

使用的技術

  • Python 3.13
  • psutil 7.2.2 —— 讀網卡累積流量
  • openpyxl 3.1.5 —— 讀寫 .xlsx(檢索結果彙整、620/680 統計)
  • xlrd 2.0.2 —— 讀 630 的舊式 .xls
  • Playwright 1.60.0 —— 傳統檢索用(只跑 API 檢索的話用不到)
  • HTML / CSS / JavaScript(免打包、無框架)

安裝說明

A. 單機

把整個 flow_check 資料夾下載到那台電腦即可(API驗證碼、設定、檢索清單一起帶走)。

B. 多機(採Google Drive 同步)

  1. 安裝Google Drive 電腦版,登入自己的Google的帳號。
  2. 在自己的雲端硬碟建立捷徑。

僅同步檢索數據、驗證碼池(各台筆數自動加總、可分台看)，流量監控數據各機獨立計算。

啟動 / 關閉

動作做法
啟動主工具雙擊 start_monitor.bat,會自動打開瀏覽器到 http://127.0.0.1:8765
關閉主工具雙擊 stop_monitor.bat(只關這個工具,不影響其他程式)
年度檢索統計雙擊 年度統計.bat，開啟獨立頁面 http://127.0.0.1:8766；關閉其命令視窗即可停止。

第一次啟動會自動安裝所需套件(psutil;傳統檢索另需 playwright / chromium),需網路、約數分鐘;之後啟動就不會再裝。

主要功能

流量監控

  • 今日用量:今天用掉 / 還剩多少流量。
  • 用量通知:達設定比例以頁內視窗 + 紅幅 + 分頁紅點提醒。
  • 限速偵測(網速):雙重確認是否超過流量限制，可被動看近期最高下載速率,或按「測速」實量(每次約 8MB)。

檢索控制台

  • 兩種檢索方式:
    • API 檢索:走官方 API,快、省流量,需驗證碼。
      • 驗證碼設定:
        • 到 GPSS API頁面 線上申請驗證碼
        • 按「新增驗證碼」，填入新申請的驗證碼
    • 傳統檢索(前端):操作 GPSS 網頁、不需驗證碼。
  • 執行檢索:填入要檢索的筆數後按「▶ 開始」;跑完該筆數,或按「■ 立即停止」就結束。

爬取統計

  • 今日進度:今天爬取筆數、和目標的差距，以及相關數據。
  • 本月 API 查詢筆數:本月使用各組驗證碼執行多少次檢索。

檢索進度

  • 本月進度:離目標(預設 45 萬筆)還差多少,進而自動計算每日目標。
  • 資料來源:GPSS 後台匯出檔,採取手動更新。

年度檢索統計（獨立工具）

  • 雙擊 年度統計.bat 開啟 http://127.0.0.1:8766；不依賴主工具，可獨立啟動與關閉。
  • 顯示內容:年度目標完成率、年度累積／年度目標／尚差，以及 620、630、680 三個系統的累積檢索次數與更新月份;按「更新統計」才重查資料。
  • 統計來源:620 讀最新月統計檔的「月份追蹤」歷史表；630 加總各月營運表「全部」工作表的合計列；680 讀最新統計總表的累計／總計列。
